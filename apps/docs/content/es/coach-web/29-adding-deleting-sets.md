# Agregar y Eliminar Series

## ¿Que es esto?

Cada ejercicio en el Constructor de Entrenamientos puede tener multiples series. Puedes agregar series para aumentar el volumen, eliminar series que no necesitas y elegir si las series comparten los mismos valores (vinculadas) o tienen valores personalizados individualmente (desvinculadas).

## ¿Por que es util?

Diferentes objetivos de entrenamiento requieren diferentes configuraciones de series. Un bloque de fuerza puede requerir 5 series de 3 repeticiones al mismo peso, mientras que una piramide de hipertrofia puede necesitar 4 series cada una con diferentes repeticiones y pesos. Las herramientas de gestion de series te dan control total sobre como se programa cada ejercicio.

## Guia Paso a Paso

### Agregar Series

1. Abre el Constructor de Entrenamientos y localiza el ejercicio que quieres modificar.
2. Haz clic en el boton **Agregar Serie** (tipicamente un icono "+") debajo de la ultima fila de series de ese ejercicio.
3. Aparece una nueva fila de serie con valores predeterminados. Ajusta repeticiones, peso, descanso y otros campos segun sea necesario.
4. Repite para agregar tantas series como necesites.

> [Screenshot: Add Set button below an exercise's set rows]

### Eliminar Series

1. Localiza la serie que quieres eliminar.
2. Pasa el cursor sobre la fila de la serie para revelar la opcion de eliminar.
3. Haz clic en el icono **Eliminar** (icono de papelera o "x") en el lado derecho de la fila de la serie.
4. La serie se elimina inmediatamente. Si el ejercicio tiene solo una serie restante, esa serie no puede ser eliminada sin eliminar el ejercicio completo.

> [Screenshot: Delete icon visible on a set row]

### Vincular y Desvincular Series

Cuando las series estan **vinculadas**, cambiar el valor en una serie aplica automaticamente el mismo valor a todas las demas series de ese ejercicio. Esto es util cuando cada serie debe tener repeticiones y peso identicos.

Cuando las series estan **desvinculadas**, cada serie tiene valores independientes. Esto es esencial para series piramidales, drop sets o cualquier esquema donde las repeticiones o el peso cambian entre series.

1. Localiza el control de vincular/desvincular en la tarjeta del ejercicio.
2. Haz clic para alternar entre los modos vinculado y desvinculado.
3. Cuando estan vinculadas, editar cualquier valor de serie actualiza todas las series.
4. Cuando estan desvinculadas, cada fila de serie puede editarse independientemente.

## Cosas a Tener en Cuenta

- Las series recien agregadas heredan los valores de la serie anterior por defecto, ahorrandote tiempo al programar series identicas.
- Eliminar una serie no se puede deshacer con un solo clic, asi que verifica antes de eliminar.
- El modo vinculado es el predeterminado para nuevos ejercicios. Cambia al modo desvinculado antes de ingresar valores diferentes.
- El numero de series se muestra en la tarjeta del ejercicio para referencia rapida.
- Las series de calentamiento se gestionan por separado y no afectan el conteo de series de trabajo.

## Preguntas Frecuentes

**¿Que pasa si vinculo las series despues de ingresar valores diferentes?**
Vincular las series despues de ingresar valores diferentes sincronizara todas las series para que coincidan con los valores de la primera serie. Asegurate de que quieres sobrescribir antes de vincular.

**¿Puedo agregar series a ejercicios dentro de un superset?**
Si. Cada ejercicio dentro de un superset, triset o giant set puede tener su propio numero de series gestionado independientemente.

**¿Hay un numero maximo de series por ejercicio?**
No hay un maximo estricto, pero la interfaz esta optimizada para volumenes de entrenamiento tipicos. Conteos de series extremadamente altos siguen siendo funcionales pero pueden requerir desplazamiento.

**¿Las series agregadas se sincronizan con la app del cliente inmediatamente?**
Los cambios se guardan cuando guardas el entrenamiento. Una vez guardado, las series actualizadas seran visibles para el cliente la proxima vez que abra el entrenamiento en la app movil.
