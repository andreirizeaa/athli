# Notas de Ejercicios

## ¿Que es esto?

Las notas de ejercicios son anotaciones de texto que puedes adjuntar a ejercicios individuales dentro del Constructor de Entrenamientos. Estas notas aparecen junto al ejercicio en la app movil del cliente, proporcionando contexto adicional, instrucciones o indicaciones que van mas alla de lo que las columnas estandar (series, repeticiones, peso) pueden transmitir.

## ¿Por que es util?

El entrenamiento es mas que solo numeros. Los clientes a menudo necesitan recordatorios de indicaciones, descripciones de tempo, modificaciones de tecnica o instrucciones especiales para ejercicios especificos. Las notas de ejercicios te permiten comunicar estos detalles directamente dentro del entrenamiento, eliminando la necesidad de mensajes o documentos separados. Esto es particularmente valioso para el coaching remoto donde no puedes dar indicaciones verbales en tiempo real.

## Guia Paso a Paso

### Agregar una Nota a un Ejercicio

1. Abre el Constructor de Entrenamientos y localiza el ejercicio que quieres anotar.
2. Haz clic en la tarjeta del ejercicio para expandir sus opciones, o busca el campo de **Notas** directamente debajo de las filas de series.
3. Haz clic en el campo de notas y escribe tus instrucciones.
4. La nota se guarda como parte de la configuracion del ejercicio dentro del entrenamiento.
5. No hay un limite estricto de caracteres, pero manten las notas concisas y accionables para mejores resultados.

### Casos de Uso Comunes para Notas de Ejercicios

Aqui hay ejemplos practicos de como usar las notas de ejercicios efectivamente:

- **Indicaciones**: "Empuja con los talones y aprieta los gluteos en la parte superior."
- **Instrucciones de tempo**: "Usa una excentrica de 3 segundos en cada repeticion."
- **Modificaciones**: "Si los hombros te molestan, usa un agarre neutro en su lugar."
- **Instrucciones especiales**: "Usa la maquina de cable en la pared del fondo, ajustada en posicion 5."
- **Orientacion de progresion**: "Agrega 2.5 kg si completaste todas las repeticiones en el extremo superior del rango la semana pasada."
- **Contexto de superset**: "Ve directo al siguiente ejercicio sin descanso."
- **Recordatorios de seguridad**: "Usa un asistente para las series 3 y 4."

## Cosas a Tener en Cuenta

- Las notas son por ejercicio, por entrenamiento. El mismo ejercicio en un entrenamiento diferente puede tener notas diferentes.
- Manten las notas concisas. Los clientes tipicamente miran las notas entre series, asi que parrafos largos pueden ser ignorados.
- Las notas soportan texto plano. El formato como negritas o puntos con vinetas puede no renderizarse en todas las versiones de la app movil.
- Puedes actualizar las notas en cualquier momento editando el entrenamiento. Las notas actualizadas son visibles para el cliente la proxima vez que abra el entrenamiento.
- Las notas no reemplazan los videos de demostracion de ejercicios. Usa videos para demostraciones de movimientos y notas para instrucciones textuales.
- Considera usar la columna de Notas (un campo rastreable) para notas por serie versus notas a nivel de ejercicio para instrucciones generales.

## Preguntas Frecuentes

**¿Los clientes pueden ver las notas antes de comenzar el entrenamiento?**
Si. Las notas son visibles cuando el cliente abre el entrenamiento y revisa los ejercicios, no solo durante el registro activo.

**¿Los clientes pueden agregar sus propias notas?**
Los clientes tipicamente pueden registrar notas personales durante su sesion de entrenamiento, separadas de las notas prescritas del entrenador.

**¿Hay un limite de caracteres para las notas?**
No hay un limite estricto de caracteres, pero mantener las notas bajo unas pocas oraciones asegura que sean leidas y utiles.

**¿Puedo copiar notas entre ejercicios?**
Puedes copiar y pegar manualmente el texto de las notas. No hay una funcion dedicada de copiar notas, pero duplicar un ejercicio lleva sus notas consigo.

**¿Las notas se sincronizan en tiempo real?**
Las notas son parte de los datos del entrenamiento. Se sincronizan cuando el entrenamiento se guarda y el cliente actualiza o abre el entrenamiento.
