# Constructor de Secciones

## ¿Que es esto?

El Constructor de Secciones te permite crear secciones de entrenamiento reutilizables en tu biblioteca. Una seccion es un grupo de ejercicios con un formato de entrenamiento especifico (series regulares, AMRAP, Tabata, HIIT, EMOM o circuitos) que puedes guardar una vez y agregar a cualquier entrenamiento.

## ¿Por que es util?

- Construye tus calentamientos, finalizadores o circuitos favoritos una vez y reusalos
- Mantiene tu programacion consistente entre clientes
- Ahorra tiempo al no reconstruir las mismas combinaciones de ejercicios repetidamente
- Comparte secciones estandarizadas entre programas y entrenamientos

## Donde encontrarlo

1. Ve a **Biblioteca** en la barra lateral.
2. Selecciona la pestaña **Entrenamiento**.
3. Haz clic en **Secciones**.

> [Screenshot 1: section library page showing list of saved sections]

## Tipos de Secciones

Cada seccion tiene un formato de entrenamiento que determina como se realizan los ejercicios:

| Tipo | Descripcion |
|------|-------------|
| **Regular** | Entrenamiento de fuerza estandar con series, repeticiones y periodos de descanso |
| **AMRAP** | Tantas Rondas/Repeticiones Como Sea Posible dentro de un limite de tiempo |
| **Tabata** | Intervalos de alta intensidad: 20s trabajo, 10s descanso, 8 rondas |
| **HIIT** | Entrenamiento de intervalos de alta intensidad con trabajo/descanso personalizable |
| **EMOM** | Cada Minuto En El Minuto con duracion establecida |
| **Circuitos** | Entrenamiento en circuito con un numero establecido de rondas |

### Configuraciones Predeterminadas

Algunos tipos de secciones vienen con valores predeterminados preestablecidos:
- **Tabata:** 20s trabajo, 10s descanso, 8 rondas
- **HIIT:** 40s trabajo, 20s descanso, 10 rondas
- **EMOM:** intervalos de 60s, 10 minutos en total
- **Circuitos:** 3 rondas

Puedes personalizar todos los valores al construir la seccion.

## Crear una Seccion

1. Haz clic en **Agregar Seccion** desde la pagina de biblioteca de secciones.
2. Se abre un panel lateral — ingresa un nombre, selecciona el tipo de seccion (Regular, AMRAP, Tabata, etc.) y agrega etiquetas opcionales.
3. Guarda para crear la seccion.
4. Haz clic en la seccion recien creada en la cuadricula para abrir el constructor de secciones.
5. Agrega ejercicios de tu biblioteca de ejercicios.
6. Configura cada ejercicio con series, repeticiones, peso, descanso u otros campos relevantes dependiendo del tipo de seccion.
7. Guarda la seccion.

## Agregar Ejercicios a una Seccion

- Haz clic en el boton **+** para navegar y agregar ejercicios de tu biblioteca.
- Arrastra los ejercicios para reordenarlos dentro de la seccion.
- Crea superseries agrupando ejercicios juntos.
- Usa el generador de IA para autocompletar una seccion desde un prompt de texto.

> [Screenshot 3: exercise selection panel within the section builder]

## Configurar Ejercicios

Dependiendo del tipo de ejercicio, puedes establecer diferentes campos por serie:

- **Peso y Repeticiones** - Para ejercicios de fuerza (ej., 4x10 @ 80kg)
- **Solo Repeticiones** - Para ejercicios con peso corporal o basados en repeticiones
- **Distancia y Duracion** - Para ejercicios de cardio (ej., 400m en 2:00)

Cada ejercicio puede tener multiples series con valores individuales. Usa el toggle vincular/desvincular para establecer todas las series con el mismo valor o personalizar cada una.

> [Screenshot 4: exercise card showing set configuration with linked values]

## Usar Secciones en Entrenamientos

Una vez guardadas en tu biblioteca, las secciones aparecen al construir entrenamientos:

1. Abre el **Constructor de Entrenamientos** (desde un programa, entrenamiento de cliente o biblioteca).
2. Haz clic en **Agregar Seccion**.
3. Navega por tus secciones guardadas y selecciona una.
4. La seccion, incluyendo todos los ejercicios y configuraciones, se agrega al entrenamiento.
5. Aun puedes personalizarla para el entrenamiento especifico sin afectar la version de la biblioteca.

## Gestionar Secciones

Desde la biblioteca de secciones, puedes:
- **Buscar** por nombre o filtrar por tipo y etiquetas
- **Editar** cualquier seccion haciendo clic en ella
- **Duplicar** una seccion para crear una variacion
- **Eliminar** secciones que ya no necesitas (eliminacion masiva soportada)

> [Screenshot 5: sections list with filters and bulk actions]

## Consejos

- Nombra las secciones descriptivamente (ej., "Calentamiento Tren Superior" o "Finalizador AMRAP 5-Min") para que sean faciles de encontrar despues.
- Usa etiquetas para categorizar secciones (ej., "calentamiento", "finalizador", "piernas").
- Construye una biblioteca de secciones para diferentes fases de entrenamiento y reusalas en todos los programas.

## Preguntas Frecuentes

### ¿Cual es la diferencia entre una seccion y un entrenamiento?

Un entrenamiento es una sesion de entrenamiento completa. Una seccion es un bloque de construccion dentro de un entrenamiento. Un entrenamiento puede contener multiples secciones (ej., una seccion de calentamiento, una seccion principal de fuerza y un circuito finalizador).

### ¿Si edito una seccion de la biblioteca, se actualiza en los entrenamientos existentes?

No. Una vez que una seccion se agrega a un entrenamiento, se vuelve independiente. Editar la version de la biblioteca no cambia los entrenamientos que ya la usan.

### ¿Puedo usar IA para generar una seccion?

Si. El constructor de secciones incluye la misma funcion de generacion con IA que el constructor de entrenamientos. Ingresa un prompt de texto y la IA sugerira ejercicios y configuracion.

### ¿Hay un limite de cuantos ejercicios puede tener una seccion?

No hay un limite estricto. Agrega tantos ejercicios como necesites para tu formato de entrenamiento.
