# Ejercicios Alternativos

## ¿Que es esto?

Los ejercicios alternativos son opciones de respaldo que puedes asignar a cualquier ejercicio en un entrenamiento. Si un cliente no puede realizar el ejercicio principal debido a disponibilidad de equipamiento, lesion o preferencia, puede cambiar al alternativo designado directamente en la app movil. Esto le da a los clientes flexibilidad sin necesitar enviarte un mensaje para una sustitucion.

## ¿Por que es util?

Los clientes entrenan en diferentes entornos. Un cliente que normalmente entrena en un gimnasio completamente equipado puede ocasionalmente entrenar en un gimnasio de hotel o en casa. Al proporcionar ejercicios alternativos, aseguras que la intencion del entrenamiento se preserve independientemente de las circunstancias. Tambien reduce la comunicacion de ida y vuelta sobre sustituciones y empodera a los clientes a mantenerse en camino independientemente.

## Guia Paso a Paso

### Establecer un Ejercicio Alternativo

1. Abre el Constructor de Entrenamientos y localiza el ejercicio al que quieres agregar un alternativo.
2. Haz clic en la tarjeta del ejercicio para expandir sus opciones, o haz clic en el **menu de tres puntos** del ejercicio.
3. Selecciona **Establecer Ejercicio Alternativo** del menu.
4. Se abre el selector de ejercicios. Busca o navega al ejercicio que quieres como alternativo.
5. Selecciona el ejercicio alternativo. Ahora esta vinculado al ejercicio principal.
6. El ejercicio alternativo aparece debajo o al lado del ejercicio principal con un indicador visual (por ejemplo, etiqueta "Alt").

## Cosas a Tener en Cuenta

- Cada ejercicio principal puede tener un ejercicio alternativo asignado.
- Los ejercicios alternativos pueden ser cualquier ejercicio de tu biblioteca, incluyendo ejercicios personalizados.
- Los alternativos no afectan el seguimiento o programacion del ejercicio principal. Existen puramente como una opcion de respaldo.
- Considera elegir alternativos que trabajen los mismos grupos musculares y patrones de movimiento que el ejercicio principal para mejores resultados.

## Preguntas Frecuentes

**¿Puedo establecer multiples alternativos para un ejercicio?**
Actualmente, cada ejercicio soporta un alternativo. Si necesitas mas opciones, considera agregar una nota al ejercicio listando alternativas adicionales.

**¿El cliente tiene que usar el alternativo?**
No. El alternativo es opcional. Los clientes siempre pueden realizar el ejercicio principal o elegir el alternativo a su discrecion.

**¿Puedo establecer el mismo alternativo para multiples ejercicios?**
Si. El mismo ejercicio puede usarse como alternativo para diferentes ejercicios principales a lo largo del entrenamiento.
