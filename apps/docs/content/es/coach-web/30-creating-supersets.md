# Crear Supersets, Trisets y Giant Sets

## ¿Que es esto?

Los supersets, trisets y giant sets son tecnicas de entrenamiento donde multiples ejercicios se realizan uno tras otro con minimo o ningun descanso entre ellos. En el Constructor de Entrenamientos, puedes agrupar ejercicios para indicar que deben realizarse como una unidad combinada.

- **Superset**: 2 ejercicios realizados uno tras otro sin descanso.
- **Triset**: 3 ejercicios realizados consecutivamente sin descanso.
- **Giant Set**: 4 o mas ejercicios realizados en secuencia sin descanso.

## ¿Por que es util?

Estas agrupaciones te ayudan a disenar entrenamientos eficientes en tiempo y de alta intensidad. Los supersets se usan comunmente para emparejar grupos musculares opuestos (por ejemplo, biceps y triceps) o para aumentar la densidad de entrenamiento. Los trisets y giant sets llevan esto mas lejos, haciendolos ideales para fases de hipertrofia o acondicionamiento. Agrupar ejercicios en el constructor asegura que tu cliente los vea como un bloque conectado en la app movil, con instrucciones claras sobre el flujo previsto.

## Guia Paso a Paso

### Crear un Superset

1. Abre el Constructor de Entrenamientos y asegurate de que los ejercicios que quieres agrupar ya esten agregados al entrenamiento.
2. Selecciona el primer ejercicio haciendo clic en su casilla de verificacion o manija de seleccion.
3. Manten presionado Shift o usa la seleccion multiple para seleccionar tambien el segundo ejercicio.
4. Haz clic en la opcion **Agrupar como Superset** que aparece en la barra de herramientas o menu contextual.
5. Los ejercicios ahora estan agrupados visualmente con un corchete o borde indicando que forman un superset.

> [Screenshot 1: Two exercises grouped as a superset with visual bracket]

### Crear un Triset o Giant Set

1. Sigue el mismo proceso de seleccion, pero selecciona 3 ejercicios para un triset o 4+ ejercicios para un giant set.
2. Usa la accion de agrupar para combinarlos. El constructor automaticamente etiqueta el grupo segun el numero de ejercicios: Superset (2), Triset (3) o Giant Set (4+).

> [Screenshot 2: Four exercises grouped as a giant set]

### Desagrupar Ejercicios

1. Haz clic en el encabezado de la seccion agrupada o selecciona el grupo.
2. Haz clic en la opcion **Desagrupar** del menu contextual o barra de herramientas.
3. Los ejercicios vuelven a ser entradas independientes en el entrenamiento.

### Configurar Descanso Entre Grupos

Despues de agrupar, puedes configurar un periodo de descanso que se aplica despues de que todo el superset, triset o giant set se complete. Este descanso es separado de cualquier descanso entre ejercicios individuales dentro del grupo (que tipicamente es cero).

1. Localiza el campo de descanso en el encabezado del grupo.
2. Ingresa el tiempo de descanso deseado (por ejemplo, 90 segundos).

## Cosas a Tener en Cuenta

- Dentro de un superset, el descanso entre ejercicios se asume como cero o minimo. El periodo de descanso que configuras se aplica despues de completar todos los ejercicios del grupo.
- Puedes arrastrar y soltar ejercicios dentro de un grupo para reordenarlos.
- Cada ejercicio en el grupo mantiene su propia configuracion de series, repeticiones y peso.
- Los clientes ven los ejercicios agrupados como un solo bloque en la app movil, dejando claro que deben realizarlos consecutivamente.
- Puedes agregar o eliminar ejercicios de un grupo existente despues de su creacion.

## Preguntas Frecuentes

**¿Puedo anidar un superset dentro de una seccion como EMOM o Circuito?**
Si. Los supersets pueden existir dentro de secciones de entrenamiento. El formato de la seccion gobierna la temporizacion general, mientras que el superset gobierna el orden de los ejercicios dentro de ella.

**¿Todos los ejercicios en un superset necesitan el mismo numero de series?**
No. Cada ejercicio puede tener un numero diferente de series, aunque es practica comun mantenerlos consistentes.

**¿Los clientes pueden omitir un ejercicio en un superset?**
Los clientes pueden registrar cada ejercicio independientemente en la app. Pueden omitir o modificar ejercicios individuales incluso dentro de un grupo.

**¿Cual es la diferencia entre un superset y un circuito?**
Un superset es tipicamente 2 ejercicios por un numero determinado de series. Un circuito involucra multiples ejercicios realizados por rondas, a menudo con una estructura basada en tiempo o rondas. Usa el tipo de seccion Circuito para formatos basados en rondas.
