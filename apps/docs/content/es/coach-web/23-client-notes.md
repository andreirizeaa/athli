# Notas del Cliente

Las notas del cliente te permiten mantener registros privados sobre cada cliente. Las notas solo son visibles para ti como entrenador y nunca se comparten con el cliente.

## Que Es

Un sistema simple de toma de notas adjunto al perfil de cada cliente. Puedes crear, editar y eliminar notas para rastrear observaciones, resumenes de sesiones, historial de lesiones, preferencias o cualquier otra cosa que quieras recordar.

## Por Que Es Util

- Mantiene un registro continuo del progreso y observaciones del cliente
- Rastrea detalles importantes como lesiones, preferencias u objetivos
- Consulta rapidamente notas anteriores antes de una sesion
- Mantente organizado con muchos clientes

## Donde Encontrarlo

1. Ve al perfil de un cliente (haz clic en cualquier cliente de tu lista de clientes).
2. Selecciona la pestaña **Notas**.

> [Screenshot: client profile with Notes tab selected showing list of notes]

## Crear una Nota

1. Haz clic en **Agregar Nota** (el boton +).
2. Ingresa un titulo para la nota.
3. Escribe el contenido de la nota en el area de texto.
4. Haz clic en **Guardar**.

> [Screenshot: create note side panel with title and content fields]

## Ver y Editar Notas

1. Haz clic en cualquier nota de la lista para abrirla en el panel lateral.
2. Edita el titulo o contenido directamente.
3. Los cambios se guardan cuando confirmas.

La lista de notas muestra:
- Titulo de la nota
- Fecha de creacion
- Una vista previa del contenido

> [Screenshot: note detail view in side panel with edit capability]

## Eliminar Notas

**Nota individual:**
1. Abre la nota.
2. Haz clic en el icono de eliminar.
3. Confirma la eliminacion.

**Eliminacion masiva:**
1. Selecciona multiples notas usando las casillas de verificacion.
2. Haz clic en el boton de eliminar que aparece.
3. Confirma la eliminacion.

> [Screenshot: notes list with multiple notes selected and delete button visible]

## Consejos

- Usa titulos descriptivos para que puedas escanear rapidamente tu lista de notas (ej., "Resumen Check-in Semana 4" en lugar de "Nota").
- Agrega notas justo despues de una sesion mientras los detalles estan frescos.
- Tambien puedes acceder a las notas del cliente desde la bandeja de entrada, para que puedas consultarlas mientras chateas.

## Preguntas Frecuentes

### ¿Pueden los clientes ver mis notas sobre ellos?

No. Las notas del cliente son completamente privadas para ti como entrenador.

### ¿Hay un limite de cuantas notas puedo crear?

No, puedes crear tantas notas como necesites por cliente.

### ¿Puedo buscar entre las notas?

La lista de notas muestra todas las notas de un cliente con titulos y fechas, facilitando encontrar lo que necesitas.
