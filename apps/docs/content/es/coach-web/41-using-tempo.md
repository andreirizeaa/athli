# Como Usar Tempo

## ¿Que es esto?

El tempo prescribe la velocidad a la que se realiza cada fase de una repeticion. Usa una notacion de 4 digitos que representa cuatro fases del movimiento: excentrica (bajar), pausa en la parte inferior, concentrica (subir) y pausa en la parte superior. Por ejemplo, un tempo de **3-1-2-0** significa 3 segundos bajando, 1 segundo de pausa en la parte inferior, 2 segundos subiendo y 0 segundos de pausa en la parte superior.

## ¿Por que es util?

Controlar el tempo es una de las formas mas efectivas de manipular el estimulo de entrenamiento sin cambiar el peso o las repeticiones. Excentricas mas lentas aumentan el tiempo bajo tension para hipertrofia. Pausas en la parte inferior eliminan el reflejo de estiramiento para mayor desarrollo de fuerza. Prescribir tempo asegura que los clientes entrenen con intencion en lugar de apresurarse a traves de las repeticiones, y estandariza el estimulo de entrenamiento entre sesiones.

## Guia Paso a Paso

### Tempo a Nivel de Ejercicio

Puedes establecer un solo tempo que aplique a todas las series de un ejercicio usando el selector de tempo a nivel de ejercicio.

1. Abre el Constructor de Entrenamientos y localiza el ejercicio donde quieres prescribir tempo.
2. Encuentra el campo de **Tempo** en la tarjeta del ejercicio.
3. Ingresa el tempo de 4 digitos usando el formato: **Excentrica-Pausa-Concentrica-Pausa** (por ejemplo, "3-1-2-0").
4. El tempo aplica a cada serie de ese ejercicio.

> [Screenshot 1: Selector de tempo a nivel de ejercicio en la tarjeta del ejercicio]

### Columna de Tempo por Serie

Alternativamente, puedes agregar una columna de Tempo para configurar diferentes tempos por serie.

1. Haz clic en un encabezado de columna para abrir el selector de campos.
2. Selecciona **Tempo** de la lista de campos disponibles.
3. La columna de Tempo aparece para ese ejercicio.
4. Ingresa un valor de tempo para cada serie individual.

> [Screenshot 2: Columna de Tempo agregada como campo por serie en el Constructor de Entrenamientos]

### Entender los Cuatro Digitos

| Posicion | Fase | Descripcion | Ejemplo (3-1-2-0) |
|----------|------|-------------|--------------------|
| 1ro | Excentrica | Fase de bajar o alargar | 3 segundos |
| 2do | Pausa (inferior) | Mantener en la posicion estirada | 1 segundo |
| 3ro | Concentrica | Fase de subir o acortar | 2 segundos |
| 4to | Pausa (superior) | Mantener en la posicion contraida | 0 segundos |

### Ejemplos Comunes de Tempo

| Tempo | Nombre | Caso de Uso |
|-------|--------|-------------|
| 2-0-2-0 | Controlado | Entrenamiento general, ritmo constante |
| 3-1-2-0 | Excentrica Lenta | Hipertrofia, enfasis en dano muscular |
| 4-0-1-0 | Enfoque Excentrico | Entrenamiento de sobrecarga excentrica |
| 3-2-1-0 | Repeticiones con Pausa | Fuerza desde parada, eliminando impulso |
| 1-0-X-0 | Explosivo | Desarrollo de potencia y velocidad ("X" significa lo mas rapido posible) |
| 5-0-5-0 | Super Lento | Tiempo bajo tension, rehabilitacion |

## Cosas a Tener en Cuenta

- La notacion "X" se usa a veces para la fase concentrica para indicar "lo mas rapido posible" o intencion explosiva.
- El tempo afecta dramaticamente la dificultad de una serie. Una serie de 8 repeticiones a tempo 3-1-2-0 toma 48 segundos, mientras que 8 repeticiones a 1-0-1-0 toma solo 16 segundos.
- Al prescribir tempo, puede que necesites reducir el peso comparado con repeticiones no controladas.
- El tempo se prescribe mas comunmente para levantamientos compuestos y trabajo de aislamiento enfocado en hipertrofia.
- No cada ejercicio necesita una prescripcion de tempo. Usalo estrategicamente para movimientos donde controlar la velocidad agrega valor.


## Preguntas Frecuentes

**¿Los clientes tienen que seguir el tempo exactamente?**
El tempo es una guia. Los clientes deben intentar coincidir con el, pero variaciones leves son normales. La intencion es controlar la velocidad de las repeticiones, no contar al segundo exacto.

**¿Puedo prescribir diferentes tempos para diferentes series del mismo ejercicio?**
Si. Si las series estan desvinculadas, cada serie puede tener su propio valor de tempo. Esto es util para progresar el tempo dentro de un ejercicio.

**¿Que significa un tempo de "0" en cualquier posicion?**
Un "0" significa que no hay pausa o retraso intencional en esa fase. El movimiento transiciona inmediatamente a la siguiente fase.

**¿Debo usar tempo para ejercicios de cardio?**
El tempo esta disenado para movimientos de entrenamiento de resistencia y no aplica a ejercicios de cardio.
