# Actividad de Pagos y Resumen

## ¿Que es esto?

La pagina de Actividad de Pagos te ofrece una vision general de todas las transacciones, suscripciones y eventos de pago dentro de tu negocio de coaching en Athli. Para una gestion financiera detallada, puedes acceder al Stripe Dashboard directamente desde Athli.

## ¿Por que es util?

Llevar un registro de los ingresos de tu coaching es esencial. La pagina de Actividad proporciona una vista rapida de las transacciones recientes sin salir de Athli, mientras que el Stripe Dashboard te da control total sobre reembolsos, disputas, pagos y reportes financieros.

## Guia Paso a Paso

### Ver Actividad de Pagos

1. Ve a **Negocio > Actividad**
2. Ves una lista de todas las transacciones, suscripciones y eventos de pago
3. Cada entrada muestra el nombre del cliente, paquete, monto, fecha y estado
4. Usa los filtros para reducir los resultados por rango de fechas, cliente o estado de pago

> [Screenshot 1: Activity page with list of transactions and filter options]

### Entender los Estados de Pago

- **Exitoso** - El pago fue procesado correctamente
- **Pendiente** - El pago esta siendo procesado por Stripe
- **Fallido** - El intento de pago no fue exitoso
- **Reembolsado** - El pago fue reembolsado a traves de Stripe
- **Cancelado** - La suscripcion fue cancelada por el cliente o el entrenador

### Acceder al Stripe Dashboard

1. Ve a **Negocio**
2. Haz clic en **Stripe Dashboard**
3. Seras llevado directamente a tu cuenta de Stripe
4. Desde alli, puedes gestionar todos los detalles financieros

> [Screenshot 2: Stripe Dashboard link in the Business section]

### Gestionar Reembolsos

1. Abre el **Stripe Dashboard** desde la pagina de Negocio
2. Encuentra la transaccion que deseas reembolsar
3. Procesa el reembolso directamente a traves de Stripe
4. El estado del reembolso se actualiza en la pagina de Actividad de Athli

Athli no gestiona reembolsos directamente. Todo el procesamiento de reembolsos debe hacerse a traves de tu Stripe Dashboard.

### Monitorear Suscripciones

1. En **Negocio > Actividad**, filtra por eventos de suscripcion
2. Ve suscripciones activas, renovaciones y cancelaciones
3. Para detalles de gestion de suscripciones, visita el Stripe Dashboard

> [Screenshot 3: Activity page filtered to show subscription events]

## Cosas a Tener en Cuenta

- Athli muestra datos de transacciones de Stripe pero no procesa pagos directamente
- Los reembolsos, disputas y ajustes de pagos se gestionan a traves de Stripe
- Stripe cobra tarifas de procesamiento estandar en cada transaccion
- Consulta la pagina de precios actual para detalles sobre las tarifas de la plataforma Athli
- Los pagos se configuran en los ajustes de tu cuenta de Stripe
- El historial de transacciones esta disponible mientras tu cuenta de Stripe este conectada

## Preguntas Frecuentes

### ¿Puedo exportar mi historial de transacciones?

Usa el Stripe Dashboard para exportar reportes financieros detallados. Stripe proporciona exportaciones en CSV y se integra con herramientas de contabilidad.

### ¿Como gestiono un pago en disputa?

Las disputas se gestionan a traves del Stripe Dashboard. Stripe proporciona herramientas de documentacion y un proceso de resolucion para cada disputa.

### ¿Por que un pago aparece como pendiente?

Los pagos pendientes aun estan siendo procesados por Stripe. Esto es normal y generalmente se resuelve en pocos minutos. Consulta el Stripe Dashboard para mas detalles.

### ¿Puedo ver a que paquete corresponde un pago?

Si. Cada transaccion en la pagina de Actividad muestra el nombre del paquete asociado junto con el cliente y el monto.

### ¿Como cambio mi calendario de pagos?

Los calendarios de pagos se configuran en los ajustes de tu cuenta de Stripe. Ve a **Stripe Dashboard > Settings > Payouts** para ajustar.
