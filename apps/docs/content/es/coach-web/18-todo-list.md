# Lista de Tareas

## Que es esto?

La seccion de Tareas te da una lista de tareas personal para gestionar tu trabajo de coaching. Incluye dos vistas: tareas generadas automaticamente por Athli (como revisiones de check-in), y tus propias tareas personalizadas.

## Por que es util

El coaching involucra muchas partes moviles. La lista de tareas te ayuda a mantener seguimiento de las cosas que necesitan tu atencion para que nada se escape.

## Casos de Uso

- Revisar envios de check-in que necesitan tu retroalimentacion
- Hacer seguimiento con un cliente sobre cambios en su programa
- Recordar crear un nuevo entrenamiento para la proxima semana
- Rastrear tareas administrativas como enviar facturas

## Guia Paso a Paso

### Ver Tareas Automatizadas (Asistente Athli)

1. Haz clic en **Tareas** en la barra lateral
2. Selecciona la pestana **Asistente Athli**
3. Veras tareas creadas por automatizaciones y flujos
4. Completa tareas marcandolas

> [Screenshot: Pestana de Tareas Asistente Athli con lista de tareas automatizadas]

### Gestionar Tus Tareas Personales

1. Haz clic en **Tareas** en la barra lateral
2. Selecciona la pestana **Tu Lista**
3. Haz clic en **Agregar Tarea** para crear una nueva tarea
4. Ingresa la descripcion de la tarea
5. Marca las tareas a medida que las completas

> [Screenshot: Pestana Tu Lista de Tareas con tareas personales y boton de agregar]

## Cosas a Tener en Cuenta

- Las tareas automatizadas son generadas por tus flujos activos
- Las tareas personales se sincronizan entre web y movil
- Las tareas completadas se ocultan pero pueden verse en el historial

---

## Preguntas Frecuentes

### Puedo establecer fechas de vencimiento en las tareas?

Las tareas personales son actualmente casillas de verificacion simples sin fechas de vencimiento.

### Puedo asignar tareas a clientes?

No. La lista de tareas es para tu gestion personal de coaching. Usa check-ins y habitos para tareas orientadas al cliente.
