# Coach Mobile: Gestion de Clientes

## Que es esto?

La pestana Clientes en la aplicacion movil de coach te permite ver tu lista de clientes, acceder a perfiles de clientes y gestionar su entrenamiento, check-ins, habitos, metricas y mas.

## Guia Paso a Paso

### Ver tu Lista de Clientes

1. Toca la pestana **Clientes** en la parte inferior de la pantalla
2. Ves todos tus clientes activos
3. Usa la barra de busqueda para encontrar un cliente especifico
4. Toca un cliente para abrir su perfil

> [Captura de pantalla: Pestana de clientes movil con lista de clientes y busqueda]

### Navegar un Perfil de Cliente

Una vez que tocas un cliente, puedes acceder a:

- **Resumen** con biografia, objetivos y lesiones
- **Entrenamiento** calendario con entrenamientos asignados
- **Check-ins** y envios
- **Habitos** y registros de finalizacion
- **Metricas** con graficos
- **Fotos** para seguimiento de progreso
- **Historial de Ejercicios** con datos de rendimiento
- **Archivos** compartidos con el cliente
- **Notas** para notas privadas de coaching

> [Captura de pantalla: Perfil de cliente movil con opciones de navegacion]

### Editar Detalles del Cliente

1. Abre el perfil de un cliente
2. Toca **Editar Detalles**
3. Actualiza su nombre, categoria, objetivos u otra informacion
4. Toca **Guardar**

> [Captura de pantalla: Pantalla de editar detalles de cliente movil]

### Ver el Calendario de Entrenamiento de un Cliente

1. Abre el perfil de un cliente
2. Toca **Entrenamiento**
3. Navega entre semanas usando las flechas
4. Toca cualquier dia para ver el entrenamiento asignado
5. Toca un entrenamiento para previsualizarlo o agregar uno nuevo

> [Captura de pantalla: Calendario de entrenamiento movil con vista semanal]

### Asignar un Entrenamiento a un Dia

1. En el calendario de entrenamiento, toca un dia vacio
2. Elige asignar un entrenamiento de tu biblioteca o crear uno
3. Selecciona el entrenamiento y confirma

## Cosas a Tener en Cuenta

- Todos los cambios se sincronizan instantaneamente con la aplicacion web
- La creacion de entrenamientos complejos (secciones, arrastrar y soltar) se hace mejor en web
- Puedes ver graficos del historial de ejercicios de cada cliente para seguir el progreso

---

## Preguntas Frecuentes

### Puedo agregar nuevos clientes desde la aplicacion movil?

Esto puede estar disponible a traves del boton de agregar. Para cargas masivas y enlaces de invitacion, usa la aplicacion web.

### Puedo archivar clientes desde el movil?

El archivado de clientes esta disponible a traves de la configuracion del cliente en su perfil.
