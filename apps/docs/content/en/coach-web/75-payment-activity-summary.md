# Payment Activity and Summary

## What is this?

The Payment Activity page gives you an overview of all transactions, subscriptions, and payment events within your Athli coaching business. For detailed financial management, you can access the Stripe Dashboard directly from Athli.

## Why is it useful?

Keeping track of your coaching income is essential. The Activity page provides a quick snapshot of recent transactions without leaving Athli, while the Stripe Dashboard gives you full control over refunds, disputes, payouts, and financial reporting.

## Step-by-Step Guide

### Viewing Payment Activity

1. Go to **Business > Activity**
2. You see a list of all transactions, subscriptions, and payment events
3. Each entry shows the client name, package, amount, date, and status
4. Use the filters to narrow results by date range, client, or payment status

> [Screenshot 1: Activity page with list of transactions and filter options]

### Understanding Payment Statuses

- **Succeeded** - Payment was processed successfully
- **Pending** - Payment is being processed by Stripe
- **Failed** - Payment attempt was unsuccessful
- **Refunded** - Payment was refunded through Stripe
- **Canceled** - Subscription was canceled by the client or coach

### Accessing the Stripe Dashboard

1. Go to **Business**
2. Click **Stripe Dashboard**
3. You are taken directly to your Stripe account
4. From there, you can manage all financial details

> [Screenshot 2: Stripe Dashboard link in the Business section]

### Managing Refunds

1. Open the **Stripe Dashboard** from the Business page
2. Find the transaction you want to refund
3. Process the refund directly through Stripe
4. The refund status updates in Athli's Activity page

Athli does not handle refunds directly. All refund processing must go through your Stripe Dashboard.

### Monitoring Subscriptions

1. In **Business > Activity**, filter by subscription events
2. See active subscriptions, renewals, and cancellations
3. For subscription management details, visit the Stripe Dashboard

> [Screenshot 3: Activity page filtered to show subscription events]

## Things to Note

- Athli displays transaction data from Stripe but does not process payments directly
- Refunds, disputes, and payout adjustments are managed through Stripe
- Stripe charges standard processing fees on each transaction
- Check the current pricing page for details on Athli platform fees
- Payouts are configured in your Stripe account settings
- Transaction history is available as long as your Stripe account is connected

## FAQs

### Can I export my transaction history?

Use the Stripe Dashboard to export detailed financial reports. Stripe provides CSV exports and integrates with accounting tools.

### How do I handle a disputed payment?

Disputes are managed through the Stripe Dashboard. Stripe provides documentation tools and a resolution process for each dispute.

### Why does a payment show as pending?

Pending payments are still being processed by Stripe. This is normal and typically resolves within a few minutes. Check the Stripe Dashboard for more details.

### Can I see which package a payment is for?

Yes. Each transaction in the Activity page shows the associated package name alongside the client and amount.

### How do I change my payout schedule?

Payout schedules are configured in your Stripe account settings. Go to **Stripe Dashboard > Settings > Payouts** to adjust.
