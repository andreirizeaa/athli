# Assigning Programs to Clients

## What is this?

Once you have created a training program in your library, you can assign it to one or more clients. Assigning a program automatically populates the client's training calendar with the scheduled workouts. You can assign the full program or just a portion of it by selecting specific start and end weeks.

## Why is it useful?

- Automates calendar population so you do not have to add workouts one by one
- Assign the same program to multiple clients, saving hours of programming time
- Choose which weeks to assign, allowing you to start clients at different phases
- Once assigned, individual workouts can be customized per client without affecting the template
- Clients immediately see their scheduled workouts in the mobile app

## Step-by-Step Guide

### Assigning a Program

1. Navigate to the client's profile.
2. Open the **Training** tab.
3. Click **Assign Program**.
4. A panel opens showing your available programs.
5. Select the program you want to assign.
6. Choose the **start week** and **end week** to define which portion of the program to assign.
   - To assign the full program, keep the default range (Week 1 to the last week).
   - To assign only part of the program, adjust the week range (e.g., Week 1 to Week 4).
7. Click **Assign**.

> [Screenshot: Assign Program side panel showing program selection and week range picker]

### What Happens After Assignment

Once you click Assign:

- The workouts from the selected weeks are placed on the client's training calendar.
- Each day that has a workout in the program template becomes a scheduled workout for the client.
- The client can see these workouts in their mobile app immediately.
- Rest days (empty cells in the program) remain empty on the client's calendar.

> [Screenshot: client's training calendar populated with workouts from an assigned program]

### Assigning Partial Programs

You do not have to assign the entire program at once. Common scenarios:

- **Phase-based assignment:** Assign Week 1-4 first, then assign Week 5-8 later after checking progress.
- **Starting mid-program:** If a client is not a beginner, assign starting from Week 5 to skip introductory weeks.
- **Testing:** Assign just Week 1 to see how the client handles the workload before committing to the full program.

### Assigning to Multiple Clients

The same program can be assigned to as many clients as you want:

1. Go to each client's Training tab.
2. Follow the same assignment steps.
3. Each client receives their own independent copy of the workouts.

> [Screenshot: two different client profiles both showing the same assigned program]

### Modifying Assigned Workouts

After a program is assigned, you can customize individual workouts for a specific client:

1. Go to the client's **Training** tab.
2. Click on any scheduled workout.
3. Make changes: add or remove exercises, adjust sets, reps, or weight.
4. Save the changes.
5. These modifications only affect this client. The original program template and other clients' assignments remain unchanged.

> [Screenshot: client's workout being edited with modified reps and weight]

## Things to Note

- Assigning a program creates independent copies of each workout for the client. Changes to the program template after assignment do not affect workouts already on the client's calendar.
- Changes to one client's assigned workouts do not affect other clients who were assigned the same program.
- You can assign different programs to different clients simultaneously.
- If you reassign the same program to a client, it adds the workouts again. It does not overwrite existing ones.
- Deleting a program from your library does not remove workouts already assigned to clients.

## FAQs

### Can I assign the same program to multiple clients?

Yes. Programs are templates. Assign them to as many clients as needed. Each client gets their own independent copy.

### If I edit the program template after assigning it, do clients see the changes?

No. Changes to the template do not retroactively update workouts already assigned to clients. Edit the client's individual workouts directly if you need to make changes.

### Can I schedule a program to start on a future date?

Yes. When assigning a program, choose a future start date. The workouts will appear on the client's calendar starting from that date.

### Can I unassign a program?

You can remove individual workouts from the client's calendar. There is no single "unassign" button that removes all workouts from a previously assigned program at once.

### What if a client already has workouts on their calendar?

Assigned program workouts are added alongside existing calendar entries. They do not replace or overwrite existing workouts.
