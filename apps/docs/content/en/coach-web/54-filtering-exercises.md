# Filtering by Muscle, Equipment, and Category

## What is this?

The left panel of the Workout Builder includes filters that let you narrow down the exercise list by muscle group, equipment type, and category. Instead of scrolling through thousands of exercises, you can apply one or more filters to quickly find what you need.

## Why is it useful?

- Find exercises targeting a specific muscle group in seconds
- Filter by available equipment to match what your client has access to
- Combine multiple filters to get highly specific results
- Speeds up workout building by reducing the time spent searching

## Step-by-Step Guide

### Filtering Exercises

1. Open the **Workout Builder** from any workout or programme.
2. In the left panel, locate the filter options above the exercise list.
3. Filter by **Muscle Group**, **Equipment**, or **Category** to narrow the list.
4. The exercise list updates immediately to show only matching exercises.

> [Screenshot 1: Workout Builder left panel with filter options and filtered exercise list]

### Combining Filters

You can apply filters from multiple categories at the same time. For example:

- **Muscle Group:** Chest + **Equipment:** Dumbbell = All dumbbell chest exercises
- **Muscle Group:** Legs + **Equipment:** Bodyweight = Bodyweight leg exercises

The exercise must match at least one selection in each active filter category.

> [Screenshot 2: Workout Builder left panel with multiple filters applied showing a refined exercise list]

### Clearing Filters

To remove filters and return to the full exercise list, click the **clear** or **reset** option in the filter panel.

## Things to Note

- Filters work on both built-in and custom exercises
- Selecting multiple options within the same filter (e.g., Chest and Back) shows exercises that target either muscle group
- Search and filters can be used together — search by name first, then apply filters to narrow results further

## FAQs

### Do filters work on custom exercises?

Yes. As long as you assigned muscle groups, equipment, and categories when creating the custom exercise, it will appear in filtered results.
