# Custom Metrics

## What is this?

Metrics are custom data points you define and assign to clients for tracking over time. Unlike habits (which are binary), metrics capture numerical values like body weight, body fat percentage, waist circumference, or any custom measurement.

## Why it is useful

Tracking numbers over time shows real progress. Metrics give you charts and history so you and your client can see trends, celebrate wins, and identify areas that need attention.

## Use Cases

- Tracking body weight weekly
- Monitoring body fat percentage monthly
- Recording custom measurements (arms, chest, waist, thighs)
- Tracking performance metrics like squat 1RM or sprint time
- Monitoring sleep hours or daily step count

## Step-by-Step Guide

### Creating a Metric

1. Go to **Library > Metrics**
2. Click **Create Metric**
3. Enter the metric name and type (weight, measurement, percentage, count, time, or custom)
4. Set the unit of measurement (kg, lbs, cm, inches, etc.)
5. Add a description (optional)
6. Organize into folders if needed
7. Click **Save**

> [Screenshot: Create metric form with type and unit selection]

### Assigning a Metric to a Client

1. Go to the client's profile
2. Click the **Metrics** tab
3. Click **Assign Metric**
4. Select from your library
5. Click **Assign**

> [Screenshot: Assign metric dialog]

### Logging Metric Values

1. Go to the client's **Metrics** tab
2. Click **Log a Metric**
3. Select the metric and enter the value
4. The date defaults to today but you can change it
5. Click **Save**

> [Screenshot: Log metric form with value input]

### Viewing Metric History and Charts

1. Go to the client's **Metrics** tab
2. Click on any assigned metric
3. You see a chart showing the value over time
4. Below the chart is a history of all logged values
5. Edit or delete individual entries as needed

> [Screenshot: Metric detail view with chart and history table]

### Organizing Metrics into Folders

1. Go to **Library > Metrics**
2. Click **Create Folder**
3. Name the folder
4. Drag metrics into the folder or use **Move to Folder**

> [Screenshot: Metrics library with folders]

## Things to Note

- Clients can log metric values from their mobile app
- You can log values on behalf of your clients from their profile
- Metric data is preserved even if you unassign the metric
- Charts automatically adjust their scale based on the data

## Common Problems

**The chart is not showing data**
Make sure at least two data points are logged. A single value will show a dot but no trend line.

**I want to change the unit on an existing metric**
Edit the metric in the Library. Note that existing logs keep their original values, so changing units on a metric with existing data may look inconsistent.

## FAQs

### Can clients see their metric charts?

Yes. Clients see their metric history and charts in the mobile app.

### Can I set target values for metrics?

This feature is not available yet. You can note targets in the metric description.

### What is the difference between metrics and habits?

Habits are binary (done/not done). Metrics track numerical values over time.

### Can I export metric data?

Metric data is viewable in chart and table format within the app. Export functionality may vary by plan.
