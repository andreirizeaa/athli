# Questionnaires

## What is this?

Questionnaires are one-time forms you send to clients to gather detailed information. Unlike check-ins which recur on a schedule, questionnaires are typically used for onboarding, assessments, or gathering specific data at a point in time.

## Why it is useful

When a new client joins, you need to learn about their history, goals, preferences, and any medical considerations. Questionnaires let you collect this in a structured format instead of a messy back-and-forth conversation.

## Use Cases

- New client intake forms collecting training history, goals, and medical information
- Pre-assessment questionnaires before program changes
- Feedback surveys after completing a program phase
- Dietary preference forms for nutrition planning

## Step-by-Step Guide

### Creating a Questionnaire

1. Go to **Library > Forms > Questionnaires**
2. Click **Create Questionnaire**
3. Add a name and description
4. Build your questions (text, number, rating, yes/no, multiple choice, scale)
5. Click **Save**

> [Screenshot: Questionnaire builder with question types]

### Assigning a Questionnaire

1. Go to the client's profile
2. Click the **Questionnaires** tab
3. Click **Assign Questionnaire**
4. Select the template
5. Click **Assign**
6. The client receives a notification to complete it

> [Screenshot: Assign questionnaire dialog]

### Reviewing Responses

1. Go to the client's **Questionnaires** tab
2. Click on any completed questionnaire
3. Review all responses
4. Download the submission if needed

> [Screenshot: Completed questionnaire with responses]

## Things to Note

- Questionnaires are one-time submissions, not recurring
- For recurring feedback, use Check-ins instead
- You can include questionnaires in your onboarding flows for automatic assignment

---

## FAQs

### What is the difference between check-ins and questionnaires?

Check-ins recur on a schedule (daily, weekly, etc.). Questionnaires are one-time submissions.

### Can I reuse questionnaire templates?

Yes. Create once in the Library and assign to any client.

### Can clients edit their response after submitting?

No. Once submitted, responses are final. The client would need to fill out a new questionnaire.
