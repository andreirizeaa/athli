# Creating Sections in a Workout

## What is this?

Sections are containers within a workout that group exercises under a specific training format. Each section has a type that defines how the exercises within it are performed. Available section types include Regular, AMRAP, EMOM, Tabata, HIIT, Circuit, and Drop Set. Sections allow you to build structured, multi-format workouts within a single session.

## Why is it useful?

Most real-world workouts combine different training styles. A session might start with heavy strength work, transition into an EMOM conditioning block, and finish with a Tabata finisher. Sections let you represent this structure clearly in the Workout Builder. Your client sees each section as a distinct block in the mobile app, complete with timers and round counters appropriate to the format.

## Step-by-Step Guide

### Creating a New Section

1. Open the Workout Builder for the workout you want to edit.
2. Click the **Create Section** button, typically located below existing content or between exercises.
3. A dropdown or modal appears asking you to choose the section type.
4. Select the desired type (e.g., AMRAP, EMOM, Tabata, Circuit).
5. The new section appears in the workout as an empty container.
6. Add exercises to the section by using the **Add Exercise** button within the section, or drag existing exercises into it.

### Configuring Section Settings

Each section type has unique configuration options:

- **Regular**: No special timing. Exercises are performed in order with standard set/rep tracking.
- **AMRAP (As Many Rounds As Possible)**: Set a time cap. Clients complete as many rounds as they can within the time limit.
- **EMOM (Every Minute On the Minute)**: Set the interval duration and total number of minutes. Clients perform the prescribed work at the start of each interval.
- **Tabata**: Fixed 20 seconds work / 10 seconds rest intervals. Configure the number of rounds.
- **HIIT**: Set custom work and rest intervals with a configurable number of rounds.
- **Circuit**: Set the number of rounds and optional rest between rounds. Exercises are performed sequentially for the prescribed rounds.
- **Drop Set**: Exercises with progressively decreasing weight within a single set sequence.

### Moving Exercises Between Sections

1. Hover over the exercise you want to move to reveal the drag handle.
2. Click and hold the drag handle.
3. Drag the exercise into the target section.
4. Release to drop it into position.

## Things to Note

- A workout can contain multiple sections of different types, allowing you to mix formats within a single session.
- Sections can be reordered by dragging the section header.
- Deleting a section removes all exercises within it, so move exercises out first if you want to keep them.
- Section-specific timers (AMRAP, EMOM, Tabata) are automatically activated in the client's mobile app during the workout.
- You can rename sections to give them descriptive labels like "Warm-Up," "Main Lift," or "Finisher."

## FAQs

**Can I have exercises outside of any section?**
Yes. Exercises can exist at the top level of the workout without being placed in a section. Only use sections when you need a specific training format.

**How many sections can a workout have?**
There is no strict limit on the number of sections per workout. Use as many as your session design requires.

**Do section timers work offline in the mobile app?**
Yes. Once the workout is downloaded, section timers function without an internet connection.

**Can I change a section's type after creating it?**
Yes. You can update the section type from its settings without losing the exercises inside it.
