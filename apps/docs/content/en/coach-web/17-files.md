# File Sharing

## What is this?

The Files section lets you upload, organize, and share documents with your clients. You can share training plans, nutrition guides, contracts, or any other files your clients need.

## Why it is useful

Instead of emailing files back and forth, you can keep everything organized in one place within the client's profile. Clients can access shared files directly from their mobile app.

## Use Cases

- Sharing a PDF nutrition plan with a client
- Uploading a training contract for reference
- Providing educational resources about exercises or techniques
- Sharing meal prep guides or recipe documents

## Step-by-Step Guide

### Uploading Files to the Library

1. Go to **Library > Files**
2. Click **Upload** and select files from your computer
3. Organize files into folders for easy access

> [Screenshot 1: Files library page with folders and upload button]

### Sharing Files with a Client

1. Go to the client's profile
2. Click the **Files** tab
3. Click **Add Files**
4. Select files from your library or upload new ones
5. The client can now access these files from their mobile app

> [Screenshot 2: Client files tab with assigned files]

### Creating and Managing Folders

1. In the Files library, click **Create Folder**
2. Name the folder
3. Drag files into the folder or use **Move to Folder**
4. Click **Edit Folder** to rename or delete

> [Screenshot 3: Folder management with create and move options]

## Things to Note

- File size limits apply. Check your plan for specific limits
- Clients can view files but cannot upload files back
- Deleting a file from the library removes it from all client profiles where it was shared

---

## FAQs

### What file types are supported?

Common formats including PDF, images (JPG, PNG), documents, and spreadsheets.

### Can clients download files to their device?

Yes. Clients can view and download files from the mobile app.

### Can I share files with multiple clients at once?

You would need to add the file to each client's profile individually.
