# Sharing Files with Clients

## What is this?

The Files feature lets you upload documents to your library and share them with individual clients. Clients can view and download shared files directly from their mobile app.

## Why is it useful?

Instead of emailing documents back and forth, you can keep everything organized within each client's profile. Training plans, nutrition guides, contracts, and educational resources are all accessible in one place for both you and your clients.

## Step-by-Step Guide

### Uploading Files to the Library

1. Go to **Library > Files**
2. Click **Upload** and select files from your computer
3. Files are stored in your library and ready to be shared

> [Screenshot: Files library with upload button and list of uploaded documents]

### Sharing Files with a Client

1. Go to the client's profile
2. Click the **Files** tab
3. Click **Add Files**
4. Select files from your existing library or upload new ones
5. The selected files are now shared with the client

> [Screenshot: Client profile Files tab with Add Files button and shared documents]

### What Clients See

1. Clients open their mobile app
2. They navigate to the files section
3. Shared files are listed with their names and file types
4. Clients can view files directly in the app
5. Clients can download files to their device

### Removing a File from a Client

1. Go to the client's profile
2. Click the **Files** tab
3. Find the file you want to remove
4. Click remove or unlink to take it off the client's profile
5. The file remains in your library for use with other clients

> [Screenshot: Client files tab showing option to remove a shared file]

## Things to Note

- Supported formats include PDF, images (JPG, PNG), documents, and spreadsheets
- File size limits depend on your plan; check your subscription details for specifics
- Clients can view and download files but cannot upload files back to you
- Deleting a file from your library removes it from all client profiles where it was shared
- You need to add files to each client profile individually; there is no bulk share option
- Organize your library with folders to keep files easy to find

## FAQs

### What file types are supported?

You can upload PDFs, images (JPG, PNG), documents (Word, Google Docs exports), and spreadsheets (Excel, CSV).

### Can clients upload files to me?

No. File sharing is one-directional. You share files with clients, but clients cannot upload files back through the platform.

### Can I share a file with multiple clients at once?

Currently, you need to add the file to each client's profile individually. There is no bulk share option.

### What happens if I delete a file from my library?

Deleting a file from the library removes it from all client profiles where it was shared. The file is permanently deleted.

### Is there a storage limit?

File storage limits depend on your plan. Check your subscription details for your current storage allowance.

### Can clients access files offline?

Clients can download files to their device for offline access. Viewing within the app requires an internet connection.
