# Logging Values and Viewing Charts

## What is this?

Once a metric is assigned to a client, you or the client can log numerical values over time. Each logged value appears as a data point on a chart, creating a visual history of progress. The chart and history table let you see trends, identify patterns, and track changes at a glance.

## Why is it useful?

A single number in isolation does not mean much. But when you plot body weight readings over 12 weeks or squat 1RM values across a training cycle, the trend tells a powerful story. Charts transform raw numbers into visual progress that motivates clients and informs your coaching decisions.

## Step-by-Step Guide

### Logging a Metric Value

1. Go to the client's profile
2. Click the **Metrics** tab
3. Click **Log a Metric**
4. Select the metric from the list of assigned metrics
5. Enter the value (e.g., 82.5 for body weight in kg)
6. The date defaults to today but you can change it to log a past value
7. Click **Save**

> [Screenshot: Log a Metric form with metric selection, value input, and date picker]

### Viewing the Metric Chart

1. Go to the client's **Metrics** tab
2. Click on any assigned metric
3. The chart displays all logged values over time on a line graph
4. Hover over data points to see the exact value and date
5. The chart auto-scales to fit the data range

> [Screenshot: Metric chart showing body weight trend over several weeks]

### Reading the History Table

Below the chart, you see a history table listing every logged entry:

- Each row shows the date, value, and unit
- Entries are sorted by date with the most recent at the top
- Click any entry to edit or delete it

> [Screenshot: Metric history table below the chart]

### Editing a Log Entry

1. Open the metric detail view
2. Find the entry in the history table
3. Click on the entry
4. Click **Edit**
5. Update the value or date
6. Click **Save**

The chart updates immediately to reflect the change.

### Deleting a Log Entry

1. Open the metric detail view
2. Find the entry in the history table
3. Click on the entry
4. Click **Delete**
5. Confirm the deletion

The data point is removed from both the chart and history.

### Clients Logging from the Mobile App

Clients can also log metric values directly from their mobile app:

1. The client opens the app and navigates to their Metrics section
2. They select the metric and enter the value
3. The log is saved and visible to both the client and the coach
4. As the coach, you see client-logged entries alongside your own entries

> [Screenshot: Client mobile view logging a metric value]

## Things to Note

- You need at least two data points for the chart to show a trend line. A single value appears as a dot.
- Charts automatically adjust their vertical scale based on the logged values.
- Both coaches and clients can log values. All entries appear in the same chart.
- The date can be set to any past date, allowing you to backfill data.

## FAQs

### Can I log multiple values for the same metric on the same day?

Yes. Each log entry is recorded separately. The chart will show all data points.

### Why is my chart not showing a line?

You need at least two data points for the chart to draw a trend line. Log a second value to see the line appear.

### Can clients see their own charts?

Yes. Clients see their metric charts and history in the mobile app.

### Can I change the date on a log entry after saving?

Yes. Edit the entry and update the date. The chart will reposition the data point accordingly.
