# Creating Habits

## What is this?

Habits are daily or weekly tasks you create in your library and assign to clients. Creating a habit involves defining its name, description, and category, and then organizing it for easy access. Once created, a habit can be assigned to any number of clients from their profile.

## Why is it useful?

Building a habit library lets you standardize the daily actions you want your clients to follow. Instead of recreating habits for each client, you create them once and reuse them across your roster. This saves time and ensures consistency in how you coach.

## Step-by-Step Guide

### Creating a Habit in the Library

1. Go to **Library > Habits**
2. Click **Create Habit**
3. Enter the **habit name** (e.g., "Drink 3L of water")
4. Add a **description** with details or instructions for the client
5. Select a **category** to group related habits together
6. Click **Save**

> [Screenshot: Create habit form with name, description, and category fields]

### Organizing Habits into Folders

1. In **Library > Habits**, click **Create Folder**
2. Name the folder (e.g., "Nutrition Habits", "Recovery Habits")
3. Drag habits into the folder or use **Move to Folder**
4. Folders keep your library clean as it grows

> [Screenshot: Habits library with folders organizing different habit categories]

### Assigning a Habit to a Client

1. Go to the client's profile
2. Click the **Habits** tab
3. Click **Assign Habit**
4. Browse or search your habit library
5. Select the habit you want to assign
6. Click **Assign**
7. The client sees the habit on their mobile app immediately

> [Screenshot: Assign habit dialog with library search]

### Assigning the Same Habit to Multiple Clients

Because habits live in your library, you can assign the same habit to as many clients as you want. Each client tracks their own completion independently.

1. Go to each client's profile
2. Follow the assignment steps above
3. The habit template remains unchanged in the library

### Editing a Habit

1. Go to **Library > Habits**
2. Click on the habit you want to edit
3. Update the name, description, or category
4. Click **Save**
5. Changes apply to future assignments; existing client assignments update as well

> [Screenshot: Editing an existing habit in the library]

## Things to Note

- Only coaches can create and assign habits. Clients cannot create their own habits.
- Habits are reusable. Create once, assign to many clients.
- Deleting a habit from the library does not remove it from clients who already have it assigned.
- You can view all assigned habits from the client's Habits tab.

---

## FAQs

### Can clients create their own habits?

No. Only coaches can create and assign habits. This ensures habits align with the coaching plan.

### Can I assign the same habit to all my clients at once?

Currently, habits are assigned per client. You assign each client individually from their profile.

### What happens if I delete a habit from the library?

Clients who already have the habit assigned will retain it. The habit is only removed from the library for future assignments.

### Can I duplicate a habit?

You can create a new habit with similar details. Copy the name and description from an existing habit to save time.
