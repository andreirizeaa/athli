# Feature Requests

The Feature Requests page lets you submit ideas for new features, vote on suggestions from other coaches, and discuss improvements with the Athli community.

## What It Is

A built-in feedback board where coaches can propose new features, upvote ideas they care about, and have conversations through replies. The most popular requests help the Athli team prioritize what to build next.

## Why It Is Useful

- Share your ideas directly with the Athli team
- Vote on features that matter most to you
- See what other coaches are requesting
- Participate in discussions about proposed features

## Where to Find It

1. Click **Feature Requests** in the sidebar (or navigate to the Features page).

> [Screenshot: feature requests page showing list of requests with vote counts]

## Submitting a Feature Request

1. Click the **+** button to open the submission dialog.
2. Enter a title that clearly describes your idea.
3. Add a detailed description explaining the feature and why it would be useful.
4. Submit.

> [Screenshot: add feature request dialog with title and description fields]

## Voting on Requests

- Click the **upvote** button on any request to show your support.
- Click it again to remove your vote.
- Requests can be sorted by popularity to see the most-voted ideas.

> [Screenshot: feature request card with upvote button and vote count]

## Viewing and Replying

1. Click on any feature request to view its full details.
2. See all replies from other coaches.
3. Click **Reply** to add your thoughts or suggestions.
4. You can sort replies by newest or oldest.

> [Screenshot: feature request detail view with replies]

## Sorting and Searching

Use the controls at the top to:
- **Search** for specific requests by keyword
- **Sort by:** Newest, Oldest, Popular, or Yours (your own submissions)

## Deleting

- You can delete your own feature requests and replies.
- Click the delete icon and confirm.

## FAQs

### Who can see my feature requests?

All coaches on the platform can see and vote on feature requests. They are community-wide.

### How does voting affect development?

The Athli team uses vote counts and discussions to help prioritize the product roadmap. Popular requests get higher priority.

### Can I edit a feature request after submitting?

Currently, you cannot edit after submission. Make sure your title and description are clear before submitting.
