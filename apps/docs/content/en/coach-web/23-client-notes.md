# Client Notes

Client notes let you keep private records about each client. Notes are only visible to you as the coach and are never shared with the client.

## What It Is

A simple note-taking system attached to each client's profile. You can create, edit, and delete notes to track observations, session summaries, injury history, preferences, or anything else you want to remember.

## Why It Is Useful

- Keep a running record of client progress and observations
- Track important details like injuries, preferences, or goals
- Quickly reference past notes before a session
- Stay organized across many clients

## Where to Find It

1. Go to a client's profile (click on any client from your client list).
2. Select the **Notes** tab.

> [Screenshot 1: client profile with Notes tab selected showing list of notes]

## Creating a Note

1. Click **Add Note** (the + button).
2. Enter a title for the note.
3. Write the note content in the text area.
4. Click **Save**.

> [Screenshot 2: create note side panel with title and content fields]

## Viewing and Editing Notes

1. Click on any note in the list to open it in the side panel.
2. Edit the title or content directly.
3. Changes are saved when you confirm.

The notes list shows:
- Note title
- Creation date
- A preview of the content

> [Screenshot 3: note detail view in side panel with edit capability]

## Deleting Notes

**Single note:**
1. Open the note.
2. Click the delete icon.
3. Confirm deletion.

**Bulk delete:**
1. Select multiple notes using the checkboxes.
2. Click the delete button that appears.
3. Confirm deletion.

> [Screenshot 4: notes list with multiple notes selected and delete button visible]

## Tips

- Use descriptive titles so you can quickly scan your notes list (e.g., "Week 4 Check-in Summary" instead of "Note").
- Add notes right after a session while details are fresh.
- You can also access client notes from the inbox, so you can reference them while chatting.

## FAQs

### Can clients see my notes about them?

No. Client notes are completely private to you as the coach.

### Is there a limit to how many notes I can create?

No, you can create as many notes as you need per client.

### Can I search through notes?

The notes list displays all notes for a client with titles and dates, making it easy to find what you need.
