# Building Questionnaires on Mobile

## What is this?

The mobile questionnaire builder lets you create one-time forms for clients directly from your phone. Questionnaires use the same question builder as check-ins but without the scheduling options, since questionnaires are single submissions rather than recurring.

## Why it is useful

Need to send a new client intake form or a quick feedback survey? You can build it on the go. The mobile builder supports the same question types as the web, so you can create any form you need without switching to a computer.

## Step-by-Step Guide

### Step 1: Navigate to the Library

Go to **Library > Forms > Questionnaires** to see your list of questionnaire templates.

> [Screenshot 1: Library Forms Questionnaires page showing the list of existing questionnaires]

### Step 2: Create a Questionnaire

1. Tap the **+** button in the top-right
2. Choose **New** to start from scratch, or **Templates** to use an existing template
3. Enter a name and description
4. Tap **Save** to create the questionnaire and open the question builder

Unlike check-ins, questionnaires have no schedule or frequency settings. They are one-time submissions.

> [Screenshot 2: Create questionnaire modal showing name and description fields]

### Step 3: Add Questions

1. In the builder, tap **Add Question**
2. Choose a question type from the list (see below)
3. Enter the question text
4. Configure any type-specific settings
5. Toggle **Required** if the client must answer
6. Tap the checkmark to add

> [Screenshot 3: Add question screen with question text field, required toggle, and type-specific settings]

### Available Question Types

| Type | Description | Settings |
|------|-------------|----------|
| **Text** | Open-ended text response | None |
| **Number** | Numeric input | None |
| **Yes/No** | Binary choice | None |
| **Multiple Choice** | Select from options | Add/remove options |
| **Scale** | Slider from 1 to 10 | Fixed 1-10 range |
| **Rating** | Star rating | None |
| **Date** | Date picker | None |
| **Images** | Photo upload | Number of photos (1-5) |
| **Videos** | Video upload | Number of videos (1-5) |
| **Signature** | Digital signature | None |

Note: Progress Photo and Metrics question types are not available for questionnaires. Those are check-in only features.

> [Screenshot 4: Question type picker showing all available question types]

### Editing a Question

1. Tap on any question card
2. Modify the text, settings, or required toggle
3. Tap the checkmark to save

You cannot change the question type after creation. Delete and re-add if you need a different type.

### Step 4: Reorder Questions

1. Tap **Reorder** (visible with 2+ questions)
2. Long-press a question and drag it to the new position
3. Tap the checkmark to confirm

> [Screenshot 5: Reorder screen with drag handles on each question card]

### Step 5: Edit Questionnaire Details

After creating a questionnaire, you can update its name or description at any time:

1. Tap the pencil icon in the builder header
2. Update the name or description
3. Tap **Save** to apply changes

> [Screenshot 6: Edit questionnaire modal showing editable name and description fields]

### Deleting a Question

1. Tap the trash icon on the question card
2. Confirm in the dialog

### Saving

Tap the checkmark in the top-right to save. The button is only active when there are unsaved changes.

## Things to Note

- Questionnaires are one-time forms. For recurring feedback, use check-ins instead
- Templates let you start from a pre-built form. Tap **Templates** when creating to browse your library
- If you navigate away with unsaved changes, you will be warned
- The question builder is identical to the check-in builder, minus the sync question types (Progress Photo and Metrics)

---

## FAQs

### What is the difference between a questionnaire and a check-in?

Check-ins recur on a schedule (daily, weekly, etc.) and support sync question types. Questionnaires are one-time submissions.

### Can I reuse a questionnaire template?

Yes. Create it once in the Library and assign it to any client.

### Can clients edit their response after submitting?

No. Once submitted, responses are final.
