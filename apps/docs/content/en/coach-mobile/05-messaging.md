# Coach Mobile: Messaging

## What is this?

The Chats tab on the coach mobile app lets you message your clients directly. Send text, images, files, audio, and react to messages, all from your phone.

## Step-by-Step Guide

### Viewing Conversations

1. Tap the **Chats** tab at the bottom of the screen
2. You see a list of all client conversations
3. Unread messages show a badge indicator
4. Tap a conversation to open it

> [Screenshot: Mobile chat list with conversations and unread badges]

### Sending Messages

1. Open a conversation
2. Type your message in the input field
3. Tap **Send**
4. You can also attach images, files, or send audio messages using the icons next to the input

> [Screenshot: Mobile chat conversation with message input]

### Sending Attachments

1. In a conversation, tap the **attachment** icon
2. Choose from camera, photo library, or file picker
3. Select the media or file
4. Add an optional caption
5. Tap **Send**

> [Screenshot: Mobile attachment options sheet]

### Viewing Archived Conversations

1. On the Chats list, tap **Archived**
2. View previously archived conversations
3. Tap to unarchive and continue chatting

> [Screenshot: Mobile archived conversations screen]

## Things to Note

- Messages sync between web and mobile in real time
- Push notifications alert you to new messages
- You can view shared documents and images within the chat

---

## FAQs

### Can I send broadcast messages from mobile?

Broadcast messaging is available on the web app.

### Can I delete a message I sent?

Yes. Long-press on a message to see options including delete.
