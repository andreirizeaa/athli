# Building Check-ins on Mobile

## What is this?

The mobile check-in builder lets you create recurring forms directly from your phone. Check-ins are forms that clients fill out on a schedule (daily, weekly, biweekly, or monthly). The builder lets you set up the schedule, add questions, and configure everything without needing the web app.

## Why it is useful

You can build or tweak check-in forms on the go. If you need to quickly add a question before a client's next submission, or create a new weekly check-in while reviewing your client list, the mobile builder has the same capabilities as the web.

## Step-by-Step Guide

### Step 1: Navigate to the Library

Go to **Library > Forms > Check-ins** to see your list of check-in templates.

> [Screenshot 1: Library Forms Check-ins page showing the list of existing check-ins]

### Step 2: Create a Check-in

1. Tap the **+** button in the top-right
2. Choose **New** to start from scratch, or **Templates** to use an existing template
3. Enter a name and description
4. Set the **schedule frequency**: Daily, Weekly, Bi-weekly, or Monthly
5. For weekly/bi-weekly schedules, select which days
6. Tap **Save** to create the check-in and open the question builder

> [Screenshot 2: Create check-in modal showing name, description, and schedule frequency options]

### Step 3: Add Questions

1. In the builder, tap **Add Question**
2. Choose a question type from the list (see below)
3. Enter the question text
4. Configure any type-specific settings (options for multiple choice, media count for photos, etc.)
5. Toggle **Required** if the client must answer
6. Tap the checkmark to add

> [Screenshot 3: Add question screen with question text field, required toggle, and type-specific settings]

### Available Question Types

**General:**

| Type | Description | Settings |
|------|-------------|----------|
| **Text** | Open-ended text response | None |
| **Number** | Numeric input | None |
| **Yes/No** | Binary choice | None |
| **Multiple Choice** | Select from options | Add/remove options |
| **Scale** | Slider from 1 to 10 | Fixed 1-10 range |
| **Rating** | Star rating | None |
| **Date** | Date picker | None |
| **Images** | Photo upload | Number of photos (1-5) |
| **Videos** | Video upload | Number of videos (1-5) |
| **Signature** | Digital signature | None |

**Sync Questions (Check-ins only):**

| Type | Description |
|------|-------------|
| **Progress Photo** | Syncs with the client's progress gallery. Limit one per form. |
| **Metrics** | Links the answer to a specific metric for automatic tracking. |

Progress Photo and Metrics are only available when creating a check-in for a specific client (not in the library).

> [Screenshot 4: Question type picker showing all available question types]

### Editing a Question

1. Tap on any question card
2. Modify the text, settings, or required toggle
3. Tap the checkmark to save

You cannot change the question type after creation. Delete and re-add if you need a different type.

### Step 4: Reorder Questions

1. Tap **Reorder** (visible with 2+ questions)
2. Long-press a question and drag it to the new position
3. Tap the checkmark to confirm

> [Screenshot 5: Reorder screen with drag handles on each question card]

### Step 5: Edit Check-in Details

After creating a check-in, you can update its name, description, or schedule at any time:

1. Tap the pencil icon in the builder header
2. Update the name, description, or schedule frequency
3. For weekly/bi-weekly schedules, change which days are selected
4. Tap **Save** to apply changes

> [Screenshot 6: Edit check-in modal showing editable name, description, and schedule fields]

### Deleting a Question

1. Tap the trash icon on the question card
2. Confirm in the dialog

### Saving

Tap the checkmark in the top-right to save. The button is only active when there are unsaved changes.

## Things to Note

- The schedule frequency is set when creating the check-in, not when adding questions
- Templates let you start from a pre-built form. Tap **Templates** when creating to browse your library
- Each form can only have one Progress Photo question
- Metric questions cannot be duplicated if the same metric is already linked
- If you navigate away with unsaved changes, you will be warned

## FAQs

### Can I change the schedule after creating a check-in?

Yes. Tap the pencil icon in the builder header to open the check-in settings and modify the schedule.

### What is the difference between creating in the Library vs for a client?

Library check-ins are reusable templates. Client check-ins are assigned directly. Progress Photo and Metrics question types are only available in the client context.

### Can I create a check-in without a schedule?

Yes. The schedule is optional and can be set later when assigning to a client.
