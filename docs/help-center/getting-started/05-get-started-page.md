# Get Started: Your First Steps in Athli

The Get Started page is your launch pad when you first sign up for Athli. It walks you through the key features and helps you set up your coaching business step by step.

## What It Is

An interactive welcome page with a feature checklist, product guides, and quick links to help you explore Athli's tools. It is designed to get you comfortable with the platform as quickly as possible.

## Why It Is Useful

- Discover all major features in one place
- Track which features you have explored
- Access demo videos, help articles, and live chat support
- Get up and running faster with guided exploration

## Where to Find It

The Get Started page appears automatically after you create your account. You can also access it anytime from the sidebar.

## Feature Checklist

The checklist guides you through Athli's core features. As you explore each one, it gets marked as complete.

Features in the checklist:

| Feature | Description |
|---------|-------------|
| **Workouts** | Build workouts with AI, create personalized training in seconds |
| **AI Assistant** | Your AI-powered coaching assistant for suggestions and automation |
| **Flows** | Build powerful automations triggered by client activity |
| **Habits** | Help clients build healthy habits with daily tracking and streaks |
| **Metrics** | Monitor weight, body measurements, or any custom metric over time |
| **Forms** | Create check-ins and questionnaires to gather client feedback |
| **Automations** | Set up automated flows to welcome new clients and collect information |

Click **Explore** on any feature to be taken to that section of the app. Your progress is tracked (e.g., "3/7 explored").

## FAQs

**Can I skip the Get Started page?**
Yes. You can navigate to any part of the app using the sidebar. The Get Started page is always accessible if you want to come back to it.

**Does the checklist reset?**
No. Your progress is saved so you can pick up where you left off.

**I have already explored everything. Can I hide the page?**
The Get Started page remains accessible from the sidebar for reference, but it does not block you from using the app normally.
