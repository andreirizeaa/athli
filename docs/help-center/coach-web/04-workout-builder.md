# Workout Builder

## What is this?

The Workout Builder is where you create and edit individual workouts. You can add exercises, organize them into sections, set reps and weights, and even use AI to generate workouts automatically.

## Why it is useful

Building workouts is the core of coaching. The workout builder gives you a flexible drag-and-drop interface to create anything from a simple circuit to a complex periodized session with supersets, drop sets, and custom sections.

## Use Cases

- Building a new workout from scratch with specific exercises
- Using AI to generate a workout based on a description
- Organizing exercises into supersets, circuits, or custom sections
- Editing an existing workout to adjust volume or intensity
- Saving a workout to your library for reuse

## Step-by-Step Guide

### Creating a New Workout

1. Go to **Library > Training > Workouts**
2. Click **New Workout**
3. Enter the workout name
4. You are now in the workout builder

> [Screenshot: Empty workout builder with name field at top]

### Adding Exercises

You have two options:

**Manual:**
1. Click **Add Exercise**
2. Search for an exercise by name or filter by muscle group
3. Click the exercise to add it
4. Set the number of sets, reps, weight, and rest time
5. Repeat for each exercise

> [Screenshot: Exercise search panel with filters and results]

**AI Generated:**
1. Click the **Athli AI** tab
2. Describe the workout you want (e.g., "Upper body push workout, 4 exercises, 4 sets each")
3. The AI generates a complete workout
4. Review and edit as needed

> [Screenshot: AI workout generation input with generated result]

### Creating Sections

Sections let you group exercises together (e.g., supersets, circuits, AMRAP blocks):

1. Click **Create Section**
2. Choose a section type (Superset, Circuit, AMRAP, EMOM, Tabata, etc.)
3. Drag exercises into the section or add new ones
4. Configure section-specific settings (rounds, rest between rounds, time cap)

> [Screenshot: Section builder with exercises grouped in a superset]

### Reordering Exercises

1. Hover over an exercise card
2. Click and hold the drag handle on the left
3. Drag the exercise to its new position
4. Release to drop

> [Screenshot: Exercise card being dragged to new position]

### Configuring Exercise Details

Each exercise card has columns you can customize:

- **Sets** - Number of sets
- **Reps** - Rep count or rep range (e.g., "8-12")
- **Weight** - Target weight or percentage
- **Rest** - Rest time between sets
- **Tempo** - Eccentric/pause/concentric timing
- **RPE** - Rate of perceived exertion
- **Notes** - Instructions for the client

> [Screenshot: Exercise card with expanded column options]

### Saving Your Workout

1. Click **Save** in the top right
2. If creating from a client's training page, the workout is assigned directly
3. If creating from the library, it is saved to your workout library

## Section Types Explained

| Type | Description |
|------|-------------|
| Superset | Two exercises performed back to back with no rest between |
| Triset | Three exercises performed back to back |
| Circuit | Multiple exercises done in sequence as rounds |
| Giant Set | Four or more exercises back to back |
| AMRAP | As Many Reps As Possible in a time limit |
| EMOM | Every Minute On the Minute |
| Tabata | Timed intervals (typically 20s work, 10s rest) |
| Drop Set | Progressive weight reduction within a set |

## Things to Note

- You can customize which columns appear for exercises in **Settings > App > Customisations**
- The exercise library contains thousands of exercises with video demonstrations
- You can create custom exercises if yours is not in the database
- Workouts saved to the library can be reused across multiple clients

## Common Problems

**I cannot find an exercise in the library**
Try different search terms. For example, search "bench press" instead of "flat barbell bench press". You can also create a custom exercise.

**My workout is not saving**
Make sure you have entered a workout name. Check that all exercises have at least a name and the required fields filled.

**The AI generated workout does not match what I wanted**
Be more specific in your description. Include details like number of exercises, sets, muscle groups, equipment available, and difficulty level.

## FAQs

**Can I duplicate a workout?**
Yes. On the workouts list page, click the menu on a workout and select **Duplicate**.

**Can I add notes to the entire workout?**
Each exercise has a notes field. For a general workout description, edit the workout details.

**How many exercises can I add to a workout?**
There is no hard limit. Add as many exercises as your workout requires.

**Can clients see exercise demonstration videos?**
Yes. If the exercise is from the built-in library, clients see video demonstrations in the mobile app.

**Can I nest sections inside sections?**
No. Sections are one level deep. You cannot put a superset inside a circuit.
