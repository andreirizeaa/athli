# To-Do List

## What is this?

The To-Do section gives you a personal task list to manage your coaching work. It includes two views: tasks generated automatically by Athli (like check-in reviews), and your own custom tasks.

## Why it is useful

Coaching involves a lot of moving parts. The to-do list helps you keep track of things that need your attention so nothing slips through the cracks.

## Use Cases

- Reviewing check-in submissions that need your feedback
- Following up with a client about their program changes
- Remembering to create a new workout for next week
- Tracking administrative tasks like sending invoices

## Step-by-Step Guide

### Viewing Automated Tasks (Athli Assistant)

1. Click **To-Do** in the sidebar
2. Select the **Athli Assistant** tab
3. You see tasks created by automations and flows
4. Complete tasks by checking them off

> [Screenshot: To-do Athli Assistant tab with automated task list]

### Managing Your Personal Tasks

1. Click **To-Do** in the sidebar
2. Select the **Your List** tab
3. Click **Add Task** to create a new task
4. Enter the task description
5. Check off tasks as you complete them

> [Screenshot: To-do Your List tab with personal tasks and add button]

## Things to Note

- Automated tasks are generated by your active flows
- Personal tasks sync between web and mobile
- Completed tasks are hidden but can be viewed in history

---

## FAQs

**Can I set due dates on tasks?**
Personal tasks are currently simple checkboxes without due dates.

**Can I assign tasks to clients?**
No. The to-do list is for your personal coaching management. Use check-ins and habits for client-facing tasks.
