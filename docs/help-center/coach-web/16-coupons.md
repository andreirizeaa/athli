# Coupons

## What is this?

Coupons let you create discount codes for your coaching packages. Clients can apply these codes at checkout to receive a percentage or fixed amount off the price.

## Why it is useful

Coupons are a great marketing tool for attracting new clients, running promotions, or rewarding loyal clients. They work directly with your Stripe-powered packages.

## Use Cases

- Offering 20% off for new clients with code "WELCOME20"
- Running a holiday promotion with a limited-time discount
- Giving existing clients a loyalty discount for renewal
- Creating referral codes for clients who bring new business

## Step-by-Step Guide

### Creating a Coupon

1. Go to **Business > Coupons**
2. Click **Create Coupon**
3. Set the discount type (percentage or fixed amount)
4. Enter the discount value
5. Optionally set an expiry date or usage limit
6. Click **Create**

> [Screenshot: Create coupon form with discount options]

### Deactivating a Coupon

1. On the Coupons page, find the coupon
2. Click **Deactivate**
3. The coupon can no longer be used at checkout

> [Screenshot: Coupon list with deactivate option]

## Things to Note

- Coupons require Stripe to be connected
- Deactivated coupons cannot be reactivated. Create a new one instead
- Coupon codes are case-insensitive

---

## FAQs

**Can I limit how many times a coupon is used?**
Yes. You can set a usage limit when creating the coupon.

**Can I create a coupon for a specific client?**
Coupons are available to anyone who has the code. For a private discount, create a unique code and share it only with that client.
