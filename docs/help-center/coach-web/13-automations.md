# Automations (Flows)

## What is this?

Flows are automation rules that trigger actions when certain events happen. For example, you can set up a flow that automatically sends a message when a client misses a check-in, or creates a task when a workout is completed.

## Why it is useful

As your client roster grows, you cannot manually follow up with every client for every missed workout or overdue check-in. Automations handle the repetitive tasks so you can focus on coaching.

## Use Cases

- Sending an automated reminder when a client misses a check-in
- Creating a to-do item when a client completes a workout (so you can review it)
- Sending encouragement when a client finishes a tough workout
- Flagging clients who have missed multiple sessions in a row

## Step-by-Step Guide

### Viewing Your Flows

1. Click **Flows** in the sidebar
2. You see a list of available automation flows
3. Each flow shows its trigger event, actions, and active/inactive status

> [Screenshot: Flows page with list of automation flows]

### Activating a Flow

1. On the Flows page, find the flow you want to enable
2. Click the **toggle** to activate it
3. The flow starts running immediately for future events

> [Screenshot: Flow card with active toggle]

### Viewing Flow Details

1. Click on any flow to see its configuration
2. You can see the trigger condition, actions, and history of executions
3. Review recent activity to make sure it is working as expected

> [Screenshot: Flow detail page with trigger and action configuration]

### Requesting a New Flow

If you need an automation that does not exist yet:

1. On the Flows page, click **Request a New Flow**
2. Describe what you need
3. The Athli team will review your request

> [Screenshot: Request new flow button]

## Available Flow Types

- **Missed Check-in** - Triggers when a client does not submit a check-in by the due date
- **Missed Workout** - Triggers when a client does not complete a scheduled workout
- **Completed Workout** - Triggers when a client finishes a workout
- **Client Onboarding** - Triggers when a new client joins (see Onboarding Flows)

## Things to Note

- Flows run automatically in the background
- You can turn flows on and off at any time
- Flow history shows you exactly when each automation ran and what it did
- Flows are available on certain plans. Check your billing page for details

## FAQs

**Can I create custom flows?**
Currently, flows are predefined by the Athli team. You can request new flows using the request feature.

**Do flows work for all clients?**
Yes. Active flows apply to all your clients automatically.

**Can I customize the message that gets sent?**
Some flows allow message customization. Check the flow details for options.

**Will I be notified when a flow runs?**
You can see flow execution history on the flow detail page. Some flows create to-do items that appear on your dashboard.
